# Kasange Secondary School Results

Frontend demo for the Kasange Secondary School Results Management System.

## Features

- Teacher result entry
- Automatic grades
- Review before submit
- Submit to Admin workflow
- Results history stored in database
- Admin login
- Admin profile + photo upload
- Admin dashboard, approval, viewing and delete workflow
- Light/Dark mode
- Responsive desktop/mobile layout

## Run locally

Requires Python 3.10+.

```bash
python server.py
